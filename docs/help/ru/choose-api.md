# Выбор API

> ChatGPT подключается напрямую к готовому OpenAI-совместимому API. Пул
> аккаунтов и локальный API Zenith Relay в этом режиме не используются.

**Подходит:** если у вас уже есть адрес API и API-ключ провайдера, а запросы должны
работать без запущенного Zenith Relay.

**Не подходит:** если нужно объединять собственные аккаунты ChatGPT в пул.
Используйте режим **Этот компьютер** или **Мой сервер**.

## Как устроен режим

В **Подключениях** сохраняются готовые API-источники. Выбранный источник
передаётся в профиль ChatGPT напрямую, поэтому после настройки приложение можно
закрыть.

Для прямого подключения профиля ChatGPT/Codex сейчас нужен источник с
**Responses API**. Источник Chat Completions можно сохранить, но действие
**Подключить ChatGPT** для него будет недоступно.

Relay разрешает передавать изображения маршрутизируемым моделям, не угадывая
поддержку по их названиям. Окончательное решение принимают выбранные провайдер
и модель.

В этом режиме нет разделов **Пул**, **API и ChatGPT** и **Использование**:
маршрутизацией, доступностью и журналами управляет сам API-провайдер. **Обзор**
показывает только те баланс и счётчики, которые умеет возвращать выбранный
провайдер.

## Вкладки приложения

В **Подключениях** добавьте и настройте API-источник, в **Обзоре** проверяйте
его состояние, доступные модели и статистику. **Пул**, **API и ChatGPT** и
**Использование** в этом режиме скрыты: Relay не маршрутизирует запросы и не
собирает собственный журнал. Поэтому показатели скорости, если провайдер их
отдаёт, относятся к его статистике; разделения на E2E и скорость генерации
здесь нет.

## Что подготовить

- Базовый HTTPS-адрес API с поддержкой Responses для подключения ChatGPT.
- API-ключ провайдера.
- Список нужных моделей или возможность получить его через API.
- Пользовательские цены только если они отличаются от цены, которую отдаёт API,
  или встроенный каталог. Они необязательны.

Управляющий токен сервера Zenith Relay здесь не подходит: нужен именно
**API-ключ провайдера для запросов**.

## Подключение API

1. Переключитесь в режим **Выбор API**.
2. Откройте **Подключения** и нажмите **Добавить API**.
3. Выберите готовый профиль провайдера или **Свой API**.
4. Укажите понятное название, базовый адрес, API-ключ провайдера и выберите
   **Responses API** для прямого подключения ChatGPT.
5. Сохраните подключение и дождитесь загрузки списка моделей.
6. В меню сохранённого источника нажмите **Подключить ChatGPT**.
7. Подтвердите создание резервной копии профиля перед переключением.

> Не вставляйте путь конкретной модели вместо базового адреса. Обычно клиенту
> нужен корень совместимого API, оканчивающийся на `/v1`.

## Как проверить работу

1. В **Подключениях** источник не должен показывать ошибку проверки.
2. В **Обзоре** выберите этот источник и проверьте список моделей.
3. Отправьте короткий запрос из ChatGPT.
4. Если провайдер поддерживает статистику, обновите **Обзор** и сравните
   количество запросов или расход.

> **Готово, если:** ChatGPT отвечает через выбранную модель после закрытия
> Zenith Relay.

## Цены и статистика

- Баланс и расход приходят из кабинета или API провайдера, если интеграция это
  поддерживает.
- Отсутствие баланса при работающих запросах может означать, что провайдер не
  отдаёт статистику, а не ошибку ключа.
- Если каталог источника отдаёт корректные цены за токены, пустые поля цены
  сначала используют их, затем проверенный глобальный каталог Relay.
- Пользовательская цена является явным переопределением для этого источника.
  Верните цену по умолчанию, чтобы снова использовать обновлённую цену API или
  глобального каталога. Пользовательская цена не меняет счёт провайдера, а
  используется для локального API-эквивалента.
- Для OpenAI-моделей используются ввод, вывод и чтение кэша. Поля записи кэша
  применяются только к семействам, где такая тарификация существует.

## Если подключение не работает

| Симптом | Что проверить | Что сделать |
| --- | --- | --- |
| `401 Unauthorized` | Ключ, срок действия и принадлежность ключа сервису | Создайте или вставьте новый API-ключ провайдера |
| `404` или модели не загружаются | Базовый адрес и совместимость API | Уберите путь модели, проверьте `/v1` и документацию сервиса |
| `429 Too Many Requests` | Баланс, квоту и лимит частоты у провайдера | Пополните баланс, дождитесь сброса или выберите другой источник |
| **Подключить ChatGPT** недоступно | Протокол сохранённого источника | Выберите **Responses API**; прямое подключение Chat Completions не поддерживается |
| Модель видна, но запрос отклонён | Поддерживаемый протокол модели | Проверьте поддержку Responses API в документации провайдера |
| Запрос отклонён после успешного подключения | Модель, инструменты, параметры и **Источник ошибки** в Использовании | **Провайдер** отклонил запрос выше по цепочке; **Аккаунт** означает ошибку учётных данных или маршрута; **Relay** означает проблему локальной настройки или преобразования |
| В Обзоре нет баланса | Поддержку статистики данным провайдером | Проверяйте кабинет провайдера; повторное добавление ключа не требуется |
| ChatGPT продолжает использовать старый адрес | Активный профиль | Снова нажмите **Подключить ChatGPT** у нужного источника |

## Ключи и восстановление

API-ключ хранится в защищённом хранилище операционной системы и не показывается
повторно целиком. В интерфейсе остаются только название, адрес, модели и
несекретные настройки.

Если после подключения нужно вернуть прежний профиль ChatGPT, откройте
**Восстановление** в режиме **Этот компьютер** и восстановите автоматическую
точку возврата.
