# Golos Text

Unmodified variable font from the Google Fonts distribution:
https://github.com/google/fonts/tree/main/ofl/golostext

Source file: `GolosText[wght].ttf`, distributed here as
`GolosText-variable.ttf`. Copyright 2019 The Golos Text Project Authors.
License: SIL Open Font License 1.1, copied in `OFL-GolosText.txt`.

The landing serves this file locally, with `font-display: swap`. No external
font API is used at runtime. The cabinet retains its existing system font stack.
